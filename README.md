# 🌴 وادنا (Ouedna) — البوابة الرقمية المركزية لولاية الوادي
> **الرابط الرسمي:** [myeloued.com](https://myeloued.com)

**وادنا** هي البوابة الرقمية الموحدة لولاية الوادي (مدينة الألف قبة - وادي سوف)، مصممة لتكون مركز انطلاق وربط ذكي بين سكان وزوار الولاية ومختلف المنصات والخدمات المحلية المعتمدة.

---

## 🏛️ بوابات المنظومة القائمة والنشطة

1. **سوق الوادي** (`https://souq.myeloued.com`)
   - منصة التجارة المحلية والإعلانات المباشرة.
   - سوق تمور دقلة نور مباشرة من مزارع الغيطان السوفية.
   - سوق السيارات ومركبات الدفع الرباعي 4x4 المهيأة للصحراء.
   - قطاع العقارات، الأراضي الفلاحية، وبساتين النخيل ومنازل القباب الأصيلة.

2. **منصة وادنا السياحية** (`https://ouedna.myeloued.com/`)
   - بوابة الحجوزات والأنشطة السياحية الصحراوية.
   - رحلات السفاري بالدفع الرباعي 4x4 والدراجات الرباعية (Quad).
   - حجز المخيمات الصحراوية والمبيت العائلي بين الكثبان الذهبية.
   - جولات استكشاف غيطان النخيل التراثية ومواسم جني التمور.

---

## 📐 معمارية المنظومة وقابلية التوسع
تم بناء البوابة وفق معمارية معيارية نظيفة وسريعة (Mobile-First)، تتيح إضافة أي بوابات رقمية أو خدمات بلدية/فلاحية/تعليمية مستقبلية تابعة للولاية تحت نفس النطاق الموحد (`*.myeloued.com`) دون المساس بالبوابات القائمة.

---

## 🚀 التقنيات وحزمة البناء (Tech Stack)

- **Framework:** [React 19](https://react.dev/) + [Vite 8](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** Alexandria Arabic Font
- **Design Philosophy:** هوية سوفية أصيلة (الكثبان الذهبية، الغروب الصحراوي، ظلال النخيل وقباب وادي سوف) بتصميم زجاجي هادئ وخفيف.

---

## 🛠️ التشغيل والتطوير المحلي

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل خادم التطوير
npm run dev

# 3. فحص الأكواد والأنواع
npm run lint

# 4. بناء نسخة الإنتاج
npm run build
```
